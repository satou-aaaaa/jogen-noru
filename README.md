# 助言に乗る？乗らない？（jogen-noru）

図を見て（点が多いのは？ 線が長いのは？）まず自分だけで答え、次に助言ロボの答えと自信（%）を見て、最後の答えを決める1日5問のゲーム。結果では、自分だけ・助言ロボだけ・最後の答えの3つの正答率と、頼りすぎ（外れた助言に乗った）・頼らなさすぎ（当たった助言を捨てた）の回数をくらべる。

遊ぶ: <https://satou-aaaaa.github.io/jogen-noru/>

- 考え方の出典: R. Parasuraman・V. Riley "Humans and Automation: Use, Misuse, Disuse, Abuse"（Human Factors 39(2), 1997）<https://doi.org/10.1518/001872097778543886> 、G. Bansal ほか "Does the Whole Exceed its Parts?"（CHI 2021）<https://arxiv.org/abs/2006.14779> ほか（画面の「このゲームについて」）。
- 助言ロボは架空で、実在の AI 製品とは関係ありません。今日の5問と上級では5問中4問だけ当たり、自信が低いときほど外れやすくしてあります。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の印・正答率が、選んだサービス（X・LINE など）に渡ります。
